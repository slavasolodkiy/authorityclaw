What happens

Inbox → local Qwen → invoice facts
Action proposal → authority gate → ALLOW / HOLD / REJECT
Valid receipt → simulated rail → payment

What the model cannot do

  • It cannot grant itself authority.
  • It cannot bypass amount, supplier or bank-detail checks.
  • It cannot keep acting after its human delegation is revoked.
  • It cannot make the rail pay without a valid receipt.

Verified run

Environment and verified boundary

Olares One with an NVIDIA GeForce RTX 5090 Laptop GPU (24 GB) and the local unsloth/Qwen3.6-27B-GGUF:Q4_K_M model running through llama.cpp.

The Olares Market NemoClaw 1.0.30 package was present on the same machine, with bundled NemoClaw v0.0.38 and OpenShell 0.0.36. This verified run used AuthorityClaw's own persistent Python harness and called the existing local model service directly. An OpenClaw-compatible authority-gate skill is included; NemoClaw/OpenClaw runtime integration was not part of this verified run.
