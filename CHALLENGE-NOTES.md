# NVIDIA London Claw Agent Challenge - verified boundary

Public project name: **AuthorityClaw**.

The verified competition run used AuthorityClaw's own long-running Python harness and the local Qwen3.6-27B model already running on the Olares One. The Olares Market NemoClaw 1.0.30 package was installed on the same machine, and an OpenClaw-compatible authority-gate skill is included, but NemoClaw/OpenClaw runtime integration is not part of the verified claim.

All payment execution is simulated. The preserved evidence records six model-backed invoice reads, seven receipts, three simulated payments and a valid receipt chain.
